# dataset/

This directory is a placeholder for the NL2SHACL-Dataset.

To populate it, clone the dataset repository into this folder:

```bash
git clone https://github.com/DE-TUM/NL2SHACL-Dataset .
```

After cloning, this directory will contain one folder per subset:

```
dataset/
├── chemrof-dataset/
├── dcat-dataset/
├── epo-dataset/
├── invoice-dataset/
├── snik-dataset/
└── dbpedia-dataset/
```

The dataset is also available on Zenodo: https://doi.org/10.5281/zenodo.20082565
